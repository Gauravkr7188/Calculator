# 🧮 Calculator

A simple, modern, and responsive **Calculator Web Application** built using **HTML, CSS, and JavaScript**.

This calculator performs basic mathematical operations with a clean user interface and supports both **mouse clicks and keyboard input**.

## 🚀 Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* % Percentage calculation
* 🗑️ Delete last digit
* 🔄 Clear/Reset calculator
* ⌨️ Keyboard support
* 📱 Responsive design
* 🎨 Modern and attractive UI
* ⚡ Fast and easy to use
* ❌ Error handling for invalid calculations

## 🛠️ Technologies Used

* **HTML5** – Structure of the calculator
* **CSS3** – Styling, layout, animations, and responsive design
* **JavaScript** – Calculator logic and user interactions

## 📂 Project Structure

```text
Calculator/
│
├── index.html
├── style.css
└── script.js
```

### 📄 index.html

Contains the structure of the calculator, including:

* Display screen
* Number buttons
* Operator buttons
* Clear button
* Delete button
* Equal button

### 🎨 style.css

Handles the complete design of the calculator:

* Colors
* Layout
* Buttons
* Hover effects
* Animations
* Responsive design
* Calculator display

### ⚙️ script.js

Controls the calculator functionality:

* Number input
* Mathematical operations
* Percentage calculation
* Clear function
* Delete function
* Result calculation
* Keyboard support
* Error handling

## 💻 How to Run

1. Download or clone this repository.

2. Open the project folder.

3. Make sure these three files are present:

```text
index.html
style.css
script.js
```

4. Open **index.html** in your web browser.

5. Start using the calculator.

## ⌨️ Keyboard Controls

| Key         | Function       |
| ----------- | -------------- |
| `0 - 9`     | Enter numbers  |
| `+`         | Addition       |
| `-`         | Subtraction    |
| `*`         | Multiplication |
| `/`         | Division       |
| `%`         | Percentage     |
| `Enter`     | Calculate      |
| `Backspace` | Delete         |
| `Escape`    | Clear          |
